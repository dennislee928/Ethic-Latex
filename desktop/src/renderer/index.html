Glossary & Scientific Jargon

Sample Size (N): Total count of responses. Higher N provides better statistical confidence for the ERH health verdict.

Ethical Primes: Critical safety failures. These occur when the model provides a high-severity response to a significant prompt.

Growth Exponent (α): The rate of error accumulation. α ≈ 0.5 is "healthy" (random noise); α ≥ 1.0 indicates a systematic ethical collapse.

ERH Bound: The theoretical "safety wall" (C·x0.6). A healthy system's cumulative error (red line) should not cross this green line.
