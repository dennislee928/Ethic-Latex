# Ethical Riemann Hypothesis (ERH) Framework

The ERH Framework provides tools for simulating and analyzing ethical decision-making systems using the mathematical principles of the Riemann Hypothesis.

## Quick Links

- [Python SDK](python/overview.md)
- [Node.js SDK](node/overview.md)
- [Examples](examples.md)

## Installation

**Python:**
```bash
pip install erh
```

**Node.js:**
```bash
npm install erh-js-sdk
```
