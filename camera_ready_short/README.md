# Short Version (8-10 pages) for Workshop/Conference Submission

This directory contains a compressed version of the full paper, suitable for workshop or conference submissions with page limits.

## Structure

The short version retains:
- Sections 1-6: Introduction, Related Work, Model Construction, ERH Statement, Simulation Setup, Results
- Sections 7.1-7.4: Selected philosophical implications (excluding detailed psychohistory)
- Section 8: AI Ethics Applications (compressed)
- Section 9: Conclusion

The short version removes or compresses:
- Detailed mathematical proofs (kept as sketches)
- Implementation details (referenced to full paper)
- Psychohistory macro-level discussion (Section 7.6) - kept as brief mention only
- Extended real-data case studies (kept as summary)
- Detailed sensitivity analysis (kept as summary table)

## How to Generate

1. Use the full paper as base: `ethical_riemann_hypothesis_en.tex`
2. Comment out or remove sections marked for compression
3. Compress remaining sections by:
   - Removing detailed proofs (keep theorem statements)
   - Condensing tables to essential metrics
   - Reducing figure count (keep Figures 1-4, remove or combine 5-7)
   - Shortening discussion sections

## Target Length

- Main text: 8-10 pages
- References: 1-2 pages
- Total: 10-12 pages
